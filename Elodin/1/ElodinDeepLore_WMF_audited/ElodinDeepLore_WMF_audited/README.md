# ElodinDeepLore

This audited package contains two usable builds plus direct-canon WMF support:

- `index.html` — landing page
- `atlas.html` — searchable lore atlas built from `data.js` + `app.js`
- `ElodinDeepLore.html` — reconstructed longform standalone dossier
- `The Name of Wind.pdf` — bundled local reference file
- `The Wise Mans Fear - Book.pdf` — bundled local WMF reference file
- `WMF_Elodin_Extraction_Audit.md` — direct-canon extraction notes
- `WMF_Elodin_Quote_Audit.json` — structured quote audit for future app ingestion

## Notes

- The atlas keeps `Canon`, `Secondary`, `Meta`, and `Theory` separated.
- The old WMF placeholder material has now been tightened with direct PDF checks.
- The longform dossier still contains theory and conjecture sections and should be reviewed against the new audit before treating every claim as settled.
- The next clean-up pass should do the same quote-by-quote tightening for *The Name of the Wind*.
